One line: the elevator pitch a city pigeon gives investors for its startup, PigeonPost 2.0 — 40,000 couriers, zero salaries because they work for crumbs, and churn that is literally zero. `main.py` writes exactly one pitch to `/output/entry.txt` and prints it: We're PigeonPost 2.0: 40,000 couriers across the city, zero salaries — they work for crumbs — and our churn is literally zero. Have you ever seen a pigeon quit?

## Run it

```sh
python3 main.py
```
